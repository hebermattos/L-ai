# Model and resource configuration

Edit the local `.env` generated by setup. Alternatively, copy `.env.example` and replace its example secret with a unique value from `openssl rand -hex 32` before running setup. Do not commit `.env`.

## Settings

| Variable | Default | Purpose |
| --- | --- | --- |
| `L_AI_MODEL` | `qwen3:4b-instruct` | Ollama model reference used to create `lai` |
| `L_AI_CONTEXT_LENGTH` | `8192` | Model context length (`num_ctx`) |
| `OLLAMA_NUM_PARALLEL` | `1` | Ollama parallel requests |
| `OLLAMA_MAX_LOADED_MODELS` | `1` | Concurrently loaded models |
| `L_AI_GPU` | `none` | Backend: `none`, `nvidia`, or `amd` |

Apply changes with:

```bash
bash scripts/setup.sh
```

Setup reads only known settings from `.env`, with nonempty process environment values taking precedence. Use unquoted `KEY=value` entries without inline comments for these settings; the script does not execute `.env` as shell code. Context and concurrency values must be positive integers. Setup downloads the selected model and renders a temporary Modelfile to update `lai`, preserving the tracked template and named data volumes.

`L_AI_GPU` selects a Compose overlay **inside setup only**. For subsequent manual Compose operations, include the matching overlay as described in [platform setup](platforms-and-gpu.md) and [upgrades](reliability.md#operations-and-upgrades).

## Resource planning

There is no fixed CPU-only or 16 GB RAM requirement. Choose model size, quantization, context, and concurrency for available RAM/VRAM. Larger contexts and simultaneous requests generally use more memory. Reduce the context or concurrency when resources are constrained. Defaults are not guaranteed hardware minimums.

Model changes may require more storage and a substantial download. Conversations and knowledge content are stored separately from the model alias. See [backup and maintenance](reliability.md#backup-and-persistence) before major changes.
